## Advice given (no action)

- **Do not put `mem_limit` on Node containers.** Node derives its heap from the cgroup limit; size the heap explicitly (`NODE_OPTIONS=--max-old-space-size`) if a cap is ever needed.
- **Do not lower the VM cap below ~5GB while Langfuse is running.** With Langfuse stopped, 4GB would hold (current use 1.2GB).
- **Closing idle Claude Code sessions** is now the larger RAM lever on the Mac than Docker.
