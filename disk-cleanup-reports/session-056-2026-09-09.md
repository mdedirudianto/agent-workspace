### Docker — narrower blast radius than S55

Unlike S55's full VM reset, this session used targeted prune commands only: `docker image prune -a -f` (unused/dangling images), `docker builder prune -f` (build cache), `docker volume prune -f` (volumes not attached to any container). None of these touch the 19 running containers or their live volumes.

### Chrome — skipped

`lsof +D` on each profile's `Service Worker` dir showed active open handles on Default, Profile 12, and Profile 3 (live tabs). Clearing while locked wouldn't reliably reclaim space and risked in-tab errors, consistent with S55's caution. User was asked how to proceed (skip / quit Chrome first / clear only the 3 unlocked profiles) and chose **skip** — disk was already out of critical territory by that point (13GB free).
