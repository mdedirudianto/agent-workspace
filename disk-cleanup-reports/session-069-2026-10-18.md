## Advice given (no action)

- **External SSD:** not recommended yet. The disk filled from the cache bug, which a bigger disk would only delay; steady-state data (Docker ~20GB, Projects 34GB) fits in 228GB. Revisit if free space still drops below ~15GB regularly 1–2 weeks after the config fix. If bought, a reputable Thunderbolt/USB4 NVMe enclosure (~2,500–3,000MB/s) is not a speed problem; the risks are throttling on cheap enclosures, disconnects while Docker or git run, and APFS ownership settings. Keep system, apps and active repos internal; put the Docker image and archived worktrees on it.
- **Next 16.2.7 has no cache size limit.** A `turbopackStaleOutputMaxAge` (one week) is documented for 16.3; whether upgrading would also stop the growth is untested.
