  "cancelled/no-show bookings only" to **any booking status**, including active
  (`PENDING`/`CONFIRMED`/`CHECKED_IN`) and `CHECKED_OUT` bookings. Still id-targeted (no
  browse-and-click list — the Trash UI's `listCancelledBookings` still only lists
  `CANCELLED`/`NO_SHOW`) and still gated behind `requireSuperAdmin`. New side-effect handling so a

  holding it (`PENDING`/`CONFIRMED`/`CHECKED_IN`), decrements `guest.totalBookings` (clamped at
  zero), and reverses `guest.totalSpent` for `CHECKED_OUT` bookings (read-then-clamp, can't go
  negative). Test file `purge.service.test.ts` extended to 13 tests covering the new branches.

No schema/migration change, no `package.json`/lockfile change, no frontend (`public`/`marketing`/
`management`) code touched — backend-only.
