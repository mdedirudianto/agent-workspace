our `app`/`proxy` production topology, pulled along harmlessly as dead config.

## Pre-deploy findings

- **Central's git tracking was healthy** (full wildcard `remote.origin.fetch`, proper
  `branch.main` upstream) — unlike the tenant clone, central was never affected by the
  fetch-refspec bug.
- Central had one leftover stash from session-004 (`vite.config.js` `allowedHosts` tweak +
  `next-env.d.ts` autogen) plus an identical uncommitted `next-env.d.ts` diff. Verified both are
  fully superseded by upstream (current `apps/management/vite.config.js` already ships the
  broader `preview: { allowedHosts: true }` fix) — dropped the stash, discarded the diff.
- Central's `apps/management/.env` had no `VITE_PUBLIC_SITE_URL(S)` key at all (not just
  outdated — absent). Added `VITE_PUBLIC_SITE_URLS={"cltest-hotel-001":"https://demo.hoteru.uk","_default":"https://demo.hoteru.uk"}`
  (hotel id + domain confirmed via `psql` query + `ALLOWED_ORIGINS`, not assumed).
- **Session-005's tenant fetch-refspec fix was incomplete.** Last session added `main` to
  `remote.origin.fetch` but left the old `+refs/heads/feat/integration-area-a-b:...` entry in
  place too — since GitHub deleted that branch, a bare `git fetch origin` still failed outright
  on it (whole command exits non-zero even though the `main` entry would have succeeded).
  **Actually fixed this time:** removed the stale entry from `remote.origin.fetch` entirely
  (`git config --unset`), leaving only the `main` refspec. Plain `git fetch`/`git pull` now work
  with no workaround needed.
- Resolved the standing proxy-access blocker from session-005: the `web-proxy` SSH alias that
  gave a host-key mismatch turned out to be a **completely unrelated host**
  (`167.172.75.187`, some other/older project) coincidentally similarly named to our real `proxy`
  (`46.250.234.153`, resolved via `/etc/hosts`) — not a security concern, just a stale/irrelevant
  known_hosts entry. `root@proxy` connects cleanly with no warnings. Both management-SPA pushes
  deferred in session-005 were completed this session as a result.
