## Deviations

| # | Deviation | Effect |
| --- | --- | --- |
| 1 | First `npm run build` failed: `/sitemap.xml` prerender queries `campaigns` at build time and the database was empty. Fixed by running `prisma migrate deploy` first, then rebuilding. | **Order matters: migrate before build** (the repo's `scripts/deploy.sh` does migrate then build too) |
| 2 | `next start` is used although `next.config.ts` sets `output: 'standalone'`; Next logs one warning at boot. Chosen over `node .next/standalone/server.js` because standalone does not carry `public/` and `.next/static` unless copied. Works; request path verified. | None; see follow-up 4 |
| 3 | Midtrans server key written **decoded**, not copied verbatim (see Findings 1) | Production authenticates |
| 4 | First apex ACME probe returned a 404 once (right after the reload), then OK on every retry, directly and through Cloudflare | None |
| 5 | Cloudflare page loads from the owner's workstation took 10–14 s per request (TCP connect to `172.67.194.32`); every other path, and `app` → Cloudflare (0.18 s), is fast | Workstation routing only; not part of the deployment |
| 6 | PM2 log timestamps are CEST (`app` clock is Europe/Berlin); the app runs with `TZ=Asia/Jakarta` | Read log times as WIB − 5 h |

## Findings

| # | Finding | Impact |
| --- | --- | --- |
| 1 | **dev `.env` `MIDTRANS_SERVER_KEY` is stored base64-encoded.** The app builds `Basic base64("<key>:")` from the raw value, so the stored form is rejected by Midtrans (401) while the decoded form authenticates (404 on a missing order). | `dev.pahala.co` very likely cannot call Midtrans as configured. Not touched; owner to fix if dev payments matter. |
| 2 | WhatsApp webhook POST with a signature of the wrong **length** throws `ERR_CRYPTO_TIMING_SAFE_EQUAL_LENGTH` in `verifyWebhookSignature` → 500 instead of 401. The request is rejected and never processed; real Meta signatures have the right length. Same code on dev. | Cosmetic/robustness; fix in the repo |
| 3 | The app has **no privacy-policy or terms page** and no change-password UI was looked for. | Owner: "leave it, follow-up". Midtrans/Meta business review may ask for them |
