**Production now runs API 0.120.3 and web 0.96.2 at `02441d13a`** (was API 0.120.2 / web 0.96.1 at `c02ff39c2`).

| Fix | What production does now |
|-----|--------------------------|
| **D10** | `POST /api/auth/refresh` refuses with a coded 401: `ACCOUNT_INACTIVE` (inactive, deleted or missing user) or `SESSION_REVOKED` (generation mismatch). A bad signature or expired token stays the uncoded 401. |
| **D12 (web)** | Web Keluar calls `POST /api/auth/logout` with its bearer **before** clearing the device, so a sign-out revokes the session server-side (on every device of that person; the confirm copy says so). | **D11 (web)** | Sign-out no longer wipes the offline sync queue; an unsent sale survives to the next sign-in. |
| **D14** | Every session end drops the user's push `devices` rows in the same transaction as the `token_version` bump. |
| **AX7 / AX7b** (review round) | Web `/api/sync/pull` GETs check the bearer still speaks for the tenant before each request; the service worker never caches `/api/sync/` (NetworkOnly). |
