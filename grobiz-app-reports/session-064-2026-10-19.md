## Findings

1. **The prod API build no longer fits Node's default heap** (D263). `tsc` on `apps/api` compiles `src/__tests__` and `src/tests` with the runtime code; this release's +16 053 lines (4 451 of them tests) pushed it to ~2.5 GB against `app`'s 2 240 MB default. Every deploy now needs the `NODE_OPTIONS` export until a test-free build config lands.
2. **`deploy.sh`'s failure path worked as designed**: no marker, no flip, lock released, and the next run's retention removed the half-built directory by itself.
3. **`origin/main` had moved past the brief's pin** (docs only). The deploy ran `origin/main` (no `--allow-ancestor`), code-identical to the pin.
4. **A real merchant's sale was refused this morning** (D262): item `(PTCGF/AZIZ) LIVE BIRD` has no valuation rate. Not caused or fixed by this deploy.
5. **The new payable code is now proven on production for both shapes** (S2, S3): the till's figure, the tender, ERPNext `rounded_total` and the paid status agree on a fractional and on a whole basket of a taxed tenant. Before the smoke the log passes had seen no sale at all since the flip, so their 0 refusals proved nothing about this code.
