| Fix | What production does now |
|-----|--------------------------|
| **FU179** | `GET /api/files/*` normalises the upstream type. jpg/png/webp/gif and PDF stay inline under `Content-Security-Policy: default-src 'none'; style-src 'unsafe-inline'; sandbox`. Every other type gets the CSP plus `Content-Disposition: attachment`. `nosniff` is on every response. |
| **D9** | The private-file `gz_at` cookie needs a live session: one `users` primary-key read, uncached. A dead session gets 401 `ACCOUNT_INACTIVE` / `SESSION_REVOKED` before anything is fetched from ERPNext. |
| **D8** | `GET /api/tenants/me/status` checks session liveness before any read. Only a merchant token may write, and it flips only a `provisioning` tenant to `failed`. A registration token is read-only. |
| **B3** | Admin Retry reopens only a `failed`/`provisioning` tenant. Anything else gets 409 `TENANT_LIVE` / `TENANT_MISSING` / `JOB_NOT_FAILED`. |
| **D20** | The worker's terminal flip to `failed` hits only a tenant that is still `provisioning`. |
| **D27** | The worker runs a job of any type only for a `provisioning`/`failed` tenant. This is an allowlist, so active, suspended, churned, pending_deletion and any future status are skipped. |
| **PIN scrub** | A job the worker skips or refuses no longer keeps the owner PIN in its metadata (SEC-013). |

## Caveats carried to the owner

- **Cached copies keep the OLD headers for up to 24h.** Cloudflare fronts `api.gro.biz.id` and caches `/api/files` (`public, max-age=86400, immutable`). The web service worker caches `/api/` GETs, and the mobile image cache keeps its own copies. **Purging `/api/files` at Cloudflare is an owner call:** on the free plan that means by URL or everything. The census found no active-content files, so the old copies are images and gz exports; the window is cosmetic, not an exposure.
- Purchase attachments of unlisted types now **download** instead of opening inline.
- Admin Retry on a live tenant now answers **409**. The admin client shows the message and ignores the code until the next admin build.
