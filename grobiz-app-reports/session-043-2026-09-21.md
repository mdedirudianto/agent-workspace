## 6. Gro (the AI assistant) — found broken, fixed, verified end-to-end

**Found broken on arrival, unrelated to this deploy.** The `ai_assistant` flag was already `enabled: true`
on `anthropic`/`claude-haiku-4-5` with an OAuth credential — but the stored session had expired
**2026-09-07 00:58 WIB** and never recovered: 1 `ok` turn (2026-09-06) against **20 `provider_error`**
across 7 tenants since, all logging `assistant OAuth refresh failed` → `401 from api.anthropic.com`.
Merchants asking Gro a question saw "asisten lagi tidak bisa dihubungi" for two weeks. Root cause
(documented in `auth.ts`'s own module docblock): a refreshable session copied from a local
`claude auth login` rotates its refresh token on every use, and the local and server-side copies
desynced.

**Fix:** owner ran `claude setup-token` locally and pasted the token into Admin → AI → Konfigurasi as a
**static** credential (no refresh token, no expiry — nothing to desync, at the cost of nothing that
renews automatically). Saved 2026-09-23 20:26:52 WIB, acknowledgement recorded.

**Verified end-to-end on the retail canary** (2026-09-23, continuing this session):
- Merchant login reports `assistantEnabled: true`.
- A typed question (`sales_summary` tool) answered correctly and matched live state: *"Belum ada
  penjualan hari ini"* (canary genuinely had 0 sales that day).
- An **explain-sourced** question (`source: explain, source_ref: sales`) answered with the fuller
  narration and was recorded with `source=explain`, `source_ref=sales` on the question row — this closes
  the CR-017 follow-up from session-041 that the write path was schema-verified but never proven live.
- Both turns: `outcome=ok`, `provider=anthropic`, `model=claude-haiku-4-5`, `auth_mode=oauth`, a real
  `cost_nano_usd` recorded.
- `GET /api/assistant/quota` correctly reflects consumption (`used: 4/100` after the run).
- Credential shape re-confirmed static after the run (no `refreshTokenEnc`).

**Accepted trade, unchanged from CR-012 §11.3:** Gro runs on one person's Pro/Max subscription, so
every merchant shares one quota ceiling and exhaustion arrives as a 429, not a billing error. The API
logs this as a warning on every boot. Switch to an API key before general launch — noted as a
