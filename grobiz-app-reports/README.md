# grobiz App Reports

App-scoped reports for the **grobiz** product (`gro.biz.id`) — a multi-tenant SaaS for Indonesian UMKM (POS / loyalty / WhatsApp) where each tenant gets its own auto-provisioned ERPNext site.
Covers cross-server work: app deploys, proxy/nginx, env/secrets, schema, ERPNext multi-tenant provisioning.

**Repo:** `github.com/biji-dev/grobiz` — pnpm monorepo (Fastify API + Vite `web`/`admin` SPAs + static `landing`).

**Server footprint:**
- `app` (`154.26.129.104` / `10.0.0.5`) — PM2: `grobiz-api` (4000, Fastify, also serves `web` SPA), `grobiz-admin` (7016, `pm2 serve --spa`), `grobiz-landing` (7017, `pm2 serve`)
- `db` (`10.0.0.1`) — PostgreSQL `grobiz`/`grobiz_user`; Redis logical **db4**
- `erp` (`10.0.0.6`) — Frappe/ERPNext v16; base site `erp.gro.biz.id` + per-tenant `<id>.gro.biz.id`; `dns_multitenant=on`, remote MariaDB on db
- `proxy` (`46.250.234.153` / `10.0.0.2`) — public nginx, TLS via wildcard `*.gro.biz.id` cert

**Subdomains:** `gro.biz.id` + `www` → landing · `app.` → web+API · `admin.` → admin SPA (+ same-origin `/api`) · `api.` → API · **`order.` → diner PWA (static on proxy, `/var/www/grobiz/order`, live since session-027)** · `erp.` / `*.` → ERPNext (wildcard)
