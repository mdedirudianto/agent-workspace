## Findings & gotchas

- **No stale-CSS window this time.** Session-002's gotcha (4 h edge TTL on un-fingerprinted `style.css`) did not
  bite: right after the swap the edge already returned the new CSS hash (`cf-cache-status: HIT`, `age: 0`), so no
  manual purge was needed from the Chrome/curl vantage point. Other Cloudflare PoPs could still hold the old copy for
  up to 4 h — if a visitor reports unstyled "Pesan" buttons, purge `https://sijari.uk/assets/style.css`
  (dashboard only; no CF token for this zone).
- **Orphaned images stay in the repo.** `merak-hitam-12/16.webp` and `sjr-hitam.webp` are still tracked in git (the
  page no longer references them), so the redeploy command must exclude them or they ship as dead weight
  (+~280 KB, publicly fetchable). They are excluded below.
- **Redeploy now excludes 6 image files** (was 2): `bos-putih.jpeg`, `surprise.jpeg`, `sijari-video-tanpa-rokok.mp4`,
  `merak-hitam-12.webp`, `merak-hitam-16.webp`, `sjr-hitam.webp`. Expected production count = 23. A cleaner fix is to
  `git rm` the three orphans and move `surprise.jpeg` / `bos-putih.jpeg` outside `assets/`.
- **Video unchanged — still the smoking-scene cut** (`sijari-video.mp4`); user did not ask to switch, deployed as-is.
- **Shop dependency:** every purchase CTA now points at `sijari.gro.biz.id/shop` (grobiz tenant storefront). If that
  tenant is renamed or paused, the site's buttons break silently — worth an Uptime Kuma check on that URL too.

## Redeploy (updated)

```bash
SP=$(mktemp -d); git clone -q https://github.com/biji-ext/sijari-web.git $SP/w && cd $SP/w
rsync -a --exclude .git --exclude .remember --exclude .playwright-mcp --exclude tools --exclude deploy \
  --exclude .DS_Store --exclude README.md --exclude CLAUDE.md --exclude .gitignore \
  --exclude bos-putih.jpeg --exclude surprise.jpeg --exclude sijari-video-tanpa-rokok.mp4 \
  --exclude merak-hitam-12.webp --exclude merak-hitam-16.webp --exclude sjr-hitam.webp \
  ./ root@46.250.234.153:/var/www/sijari.uk.new/
ssh root@46.250.234.153 'cd /var/www && chown -R www-data:www-data sijari.uk.new && find sijari.uk.new -type f | wc -l && find sijari.uk.new -name ".*" -not -path sijari.uk.new | wc -l'  # expect 23 / 0
# hash-compare (shasum -a 256 vs sha256sum), then:
ssh root@46.250.234.153 'cd /var/www && rm -rf sijari.uk.prev && mv sijari.uk sijari.uk.prev && mv sijari.uk.new sijari.uk'
# nginx change? scp deploy/sijari.uk.conf, back up the old one, nginx -t && systemctl reload nginx
# CSS changed? purge https://sijari.uk/assets/style.css in Cloudflare if the edge serves the old one
```

**Rollback:** `/var/www/sijari.uk.prev` holds the `8980049` site (25 files). To revert:
`cd /var/www && mv sijari.uk sijari.uk.bad && mv sijari.uk.prev sijari.uk` (no nginx change involved), then purge `style.css`.
