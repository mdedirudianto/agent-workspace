## Findings & gotchas

- **Stale CSS from the Cloudflare edge.** Right after the swap the edge served the *old* `style.css` (4 h edge TTL,
  filename not fingerprinted) against the *new* HTML → old CSS asked for the removed `krona-one.woff2` (404).
  Origin was correct (checked with `curl --resolve`). Fixed by a manual purge — **no CF API token exists for this
  zone**, so every `style.css` change needs a dashboard purge (Caching → Purge → Custom URL). Order matters:
  purge immediately after the swap, or accept a broken window.
- **My Playwright profile also cached the old CSS**, so a post-purge check in the same profile still showed
  Krona One + a font 404. A fresh `browser.newContext()` was clean. Verify with an isolated context, not the
  shared profile.
- **Video ships as-is (owner's call):** `index.html` uses `sijari-video.mp4`, which per the repo's `CLAUDE.md`
  has a smoking scene (PP 28/2024 says not to show people smoking). The alternative
  `sijari-video-tanpa-rokok.mp4` exists in the repo but is **not deployed**. Revisit — a one-line `index.html`
  change + redeploy.
- **Repo files deliberately not deployed:** `assets/img/bos-putih.jpeg` (unreferenced) and
  `sijari-video-tanpa-rokok.mp4` (unreferenced). Production is therefore 2 files short of `git ls-files`.
- **Stale files removed** by the directory swap (old `logo.webp`, `wordmark.webp`, Krona One / Literata fonts) —
  intentional, unlike a plain `rsync` without `--delete`.
- **CF Web Analytics beacon** is still blocked by CSP (`script-src 'self'`) — the pre-existing cosmetic console
  error; follow-up unchanged.

## Redeploy (updated — from the repo, staged + swapped)

```bash
SP=$(mktemp -d); git clone -q https://github.com/biji-ext/sijari-web.git $SP/w && cd $SP/w
rsync -a --exclude .git --exclude .remember --exclude .playwright-mcp --exclude tools --exclude deploy \
  --exclude .DS_Store --exclude README.md --exclude CLAUDE.md --exclude .gitignore \
  --exclude bos-putih.jpeg --exclude sijari-video-tanpa-rokok.mp4 ./ root@46.250.234.153:/var/www/sijari.uk.new/
ssh root@46.250.234.153 'cd /var/www && chown -R www-data:www-data sijari.uk.new && find sijari.uk.new -name ".*" -not -path sijari.uk.new | wc -l'  # expect 0
# hash-compare (shasum -a 256 vs sha256sum), then:
ssh root@46.250.234.153 'cd /var/www && rm -rf sijari.uk.prev && mv sijari.uk sijari.uk.prev && mv sijari.uk.new sijari.uk'
# nginx change? scp deploy/sijari.uk.conf, back up the old one, nginx -t && systemctl reload nginx
# then purge https://sijari.uk/assets/style.css in Cloudflare if it changed
```

**Rollback:** the `.prev` dir and vhost backup were deleted after verification, so there is no on-server rollback copy. To go back, redeploy an earlier commit from `biji-ext/sijari-web` (and its `deploy/sijari.uk.conf`).
