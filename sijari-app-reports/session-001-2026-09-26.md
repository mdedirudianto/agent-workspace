### TLS: HTTP-01, not DNS-01

Same situation as `avilia.id`: **no Cloudflare API token exists for this zone**, and Cloudflare passes
plain HTTP through to the origin (probed before issuing), so **HTTP-01 webroot** works and renews.
Consequence: **not a wildcard** — a new subdomain needs the cert re-issued with an extra `-d`. If the zone
ever enables "Always Use HTTPS", renewal breaks and DNS-01 (needs a CF token) becomes necessary.

## Design summary

- **Direction:** "botanical plate on forest ground". The logo (dark green leaves, gold buds, gold wordmark)
  only reads on a dark ground, so the palette is sampled from it: `#0f1f14` ground, `#17301d` band,
  `#e6be6e` wordmark gold, `#f0d282` highlight, `#ece5cf` text.
- **Type:** Krona One (wide extended grotesque, closest free match to the wordmark) for display and prices;
  Literata for reading text. Both self-hosted (96 KB), no third-party requests.
- **Sections:** hero with the large logo + 21+ notice · nine packs on a shelf line with per-pack prices for

- **Motion:** one page-load sequence (logo settles, one gold sheen clipped to the logo's own shape, then

  and number, PWA/service worker, the separate `/kemitraan` page (now a section). The health-warning
  artwork on every pack is shown **as-is, uncropped**. No product claims beyond the source's copy.

## nginx (`/etc/nginx/sites-available/sijari.uk.conf`, symlinked)

- Port 80: ACME `/.well-known/acme-challenge/` → `/var/www/certbot`; everything else `301 https://sijari.uk`.
- `www` 443 block → 301 to apex. Apex serves `/var/www/sijari.uk`, real 404s (`error_page 404 /404.html`,
  no SPA fallback), dotfiles → 404.
- Security headers at **server** level, no location uses `add_header` (that would silently drop the inherited
  ones): HSTS `max-age=31536000` (no `includeSubDomains`), `nosniff`, `X-Frame-Options: DENY`,
  `Referrer-Policy`, `Permissions-Policy`, and a strict CSP
  (`default-src 'self'; script-src 'none'; style-src 'self'; img-src 'self' data:; font-src 'self'; …`).
- Caching via `expires` (which does not interfere with `add_header`): HTML/robots/sitemap **revalidate**
  (`no-cache`), `/assets/` 30 d, `style.css` 1 h. Asset filenames are **not fingerprinted**, so a long
  `immutable` cache would have been a bug; images/fonts must be renamed if replaced.
- Per-vhost `gzip_types` (global config only compresses `text/html`).

## Findings

- **Source pack cutouts were defective.** The background remover had punched stepped transparent holes in the
  white shirt collar of the health-warning photo (and left checkerboard scraps on `sijari-putih`). Invisible on
  the source's light page, obvious on a dark ground. Fixed by treating each box pack as a convex hexagon and
  filling holes inside its hull from the nearest opaque colour (`tools/make-images.py`); the two flip-top BOS
  packs (loose sticks, non-convex) were left as-is and were clean.
- **`.remember/` was rsynced to production by mistake.** The Remember plugin writes `.remember/` (session
  logs) into the project directory; my rsync excluded `.git`/`tools`/`deploy` but not it. Caught from the
  post-copy file listing, deleted with a path-scoped `rm` **before the vhost existed** (so it was never
  reachable), and re-verified: 22 expected files, 0 dotfiles, hashes identical. Redeploy command below now
  excludes it, and the vhost returns 404 for any dotfile as a second line of defence.
- **Cloudflare Web Analytics beacon vs. strict CSP.** Cloudflare auto-injects
  `static.cloudflareinsights.com/beacon.min.js` at the edge; `script-src 'none'` blocks it, so **every page
  load logs one CSP console error** and no analytics are collected. Cosmetic, left as approved. Two options in
  follow-ups.
- **Cloudflare overrides CSS cache lifetime:** origin says 1 h, the edge serves `max-age=14400` (4 h browser
  TTL). A CSS change can take up to ~4 h to reach returning visitors unless the zone cache is purged.
- **`nginx -t` prints ~15 `protocol options redefined` warnings** from *other* vhosts (meetgrab, asiaweek,
  eventopia, gro, …) — pre-existing, none from `sijari.uk.conf`. Harmless; not touched.
- **`certbot renew --dry-run` sleeps up to ~5 min** in non-interactive mode (random delay), which looks like a
  hang. Real renewals are handled by `certbot.timer` / `snap.certbot.renew.timer` (both present on `proxy`).
- **An empty `.git/` appeared in `~/Projects/sijari-uk` at 09:33** (no commits, no remote) that this session
  did not create — left untouched.

```bash
cd ~/Projects/sijari-uk
rsync -a --exclude .git --exclude .remember --exclude tools --exclude deploy --exclude .DS_Store \
  ./ root@46.250.234.153:/var/www/sijari.uk/
ssh root@46.250.234.153 'chown -R www-data:www-data /var/www/sijari.uk && find /var/www/sijari.uk -name ".*" -not -path /var/www/sijari.uk | wc -l'   # expect 0
```

Hash-compare local vs. remote afterwards (`shasum -a 256` vs `sha256sum`), and purge the Cloudflare cache if
`style.css` changed. Rollback of the whole site: remove the `sites-enabled` symlink + `sites-available` file,
`nginx -t && systemctl reload nginx`, `certbot delete --cert-name sijari.uk`, `rm -rf /var/www/sijari.uk`.
