## Env decision

User chose to **consolidate now** rather than leave the two legacy vars in place. In
`~/meetgrab/apps/api/.env`:

```bash
cp .env .env.bak-preconsolidate-20260802
VAL=$(grep '^ADMIN_METRICS_TOKEN=' .env | cut -d= -f2-)
sed -i '/^ADMIN_METRICS_TOKEN=/d; /^ADMIN_BILLING_TOKEN=/d' .env
echo "ADMIN_TOKEN=$VAL" >> .env
```

Preserves the existing metrics-token value under the new canonical name (no session invalidation
for the live admin dashboard), drops both legacy vars, keeps a timestamped `.env` backup. Secret
value never echoed to a terminal at any point.
