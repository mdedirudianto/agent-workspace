## Goal

Prod was 25 commits behind `main` (last redeployed session-010, 2026-07-14). The gap is a single feature: optional Google sign-in + a Pro tier via Better Auth. Analyze the gap, redeploy api + web, then turn the feature on for real users by running the new migration and setting the four auth env vars — including generating a fresh production `BETTER_AUTH_SECRET` (explicitly not reusing the dev value).
