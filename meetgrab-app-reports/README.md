# meetgrab App Reports

App-scoped reports for the **meetgrab** product (`meetgrab.us`) — a Chrome extension that turns Google Meet captions into AI meeting summaries, backed by a stateless LLM-proxy API and an Astro marketing site.

**Repo:** `github.com/biji-dev/meetgrab` (pnpm + turbo monorepo). Apps: `api` (Hono/Node), `web` (Astro static), `admin` (Vite SPA — **not deployed yet**), `extension` (Chrome Web Store — not server-deployed). Packages: `shared-types`, `prompts`, `ui`.

**Server footprint:**
- `app` (`154.26.129.104` / `10.0.0.5`) — `meetgrab-api` under **PM2** (Hono on Node), **private-bound `10.0.0.5:8930`**, `node --env-file`. Source at `~/meetgrab` (devops). **No Docker** (repo ships a Dockerfile/compose for a DO droplet; we run native PM2 per app-server convention).
- `proxy` (`46.250.234.153`) — public nginx; terminates TLS for `meetgrab.us`, `www`, `api.meetgrab.us`. Serves the Astro static build from `/var/www/meetgrab.us`; reverse-proxies `api.` → `10.0.0.5:8930`. CF orange-cloud → Full(strict). LE cert via DNS-01 (`/etc/letsencrypt/cloudflare-meetgrab.ini`).
- `monitor` (`10.0.0.3`) — GlitchTip (`errors.biji.uk`, API project **14**), OpenPanel (`analytics.biji.uk`, shared **MeetGrab Web** project), OpenObserve (logs via `app` fluent-bit glob).
- `db` (`10.0.0.1`) — **Postgres `meetgrab` DB** (session-007): `uninstall_feedback`, `usage_daily`, `usage_user` tables. User `meetgrab`.

**Architecture note (subdomain, not `/api`):** the API is a separate subdomain `api.meetgrab.us`. The extension ships pointing at it; CORS in `apps/api/src/app.ts` whitelists `chrome-extension://<32-char>` + `https://meetgrab.us` only. The marketing site does **not** call the API.

**Current deployed SHA:** api **`b8b9e8b`** (main, 2026-08-31, api **v0.20.0**); web **`b8b9e8b`** (**v0.18.0**); admin unchanged at **v0.7.0** (`3d92282`, session-014). Deployed session-016. Billing island is live but **inert** — `PRO_BILLING_ENFORCED=false`, no PayPal creds, checkout 503s / webhooks 404. **Midtrans SANDBOX demo is enabled on production** (`MIDTRANS_SANDBOX_ENABLED=true`, session-016) for a merchant-registration review window — a real (fake-money) Snap popup reachable at `/id/checkout`; not a real billing provider, writes nothing to the database, no PayPal/entitlement code touched. **Flip off once Midtrans's review completes** (see session-016 §Still open). Migrations applied through **`0006`**. **`DAILY_SPEND_CAP_USD=0` (unlimited, testing posture, no automatic expiry — session-015).**

**Auth / LLM:** primary = Anthropic **Claude Sonnet 5** (`claude-sonnet-5`, switched session-013) via **OAuth** subscription token (reused from dogfooding; `ANTHROPIC_AUTH_MODE=oauth`, static `sk-ant-oat01-…`, **no refresh token** → may expire, watch for 401s). Large-tier escalation = **Opus 5** (`claude-opus-5`, rarely fires — both tiers are 1M-window). Fallback = **Gemini 2.5 Flash** (`GOOGLE_AI_API_KEY`). Cost circuit-breaker `DAILY_SPEND_CAP_USD=20`; rate limit 30/IP/day. AI SDK is `ai@5` + `@ai-sdk/{anthropic,google}@2` (upgraded from `ai@4` session-013 — v4 hardcoded a `temperature` default that Claude 5-series models reject with `400`).

**Observability env:** GlitchTip API DSN `…@errors.biji.uk/14` ✓; **web GlitchTip DSN `…@errors.biji.uk/16`** (project `MeetGrab-Web`, org GrabFamily/team TheGrab) ✓; OpenPanel server-side reuses the **MeetGrab Web** project's write client (`d524407b…` + secret) ✓; web GA4 `G-KMVL074MH2` + OpenPanel `analytics.biji.uk` baked into build ✓; OpenObserve auto-ships meetgrab-api PM2 JSON logs via the existing `app` fluent-bit glob (`default/app` stream) ✓.
